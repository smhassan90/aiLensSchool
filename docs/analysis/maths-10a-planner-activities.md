# Class 10A Maths — planner activity days (verification)

**Status:** Waiting on production pack refresh after deploy. Full teacher browser pass requires `TEACHER_PASSWORD` in the environment.

## How to complete verification

1. Confirm GitHub Action **Deploy HawkNexa VPS** is green for `main`.
2. Log in at [https://hawknexa.fynals.com/login](https://hawknexa.fynals.com/login) as the TPS Class 10 Maths teacher.
3. Create a **new** Class 10A Maths planner that includes **Unit 30 — Introduction to Trigonometry**.
4. Click **Build schedule** / generate and wait until the calendar has lessons.
5. Open the Unit 30 **Activity** day and copy the full card text below.
6. Run `python3 scripts/diagnose-unit-30-activity-gate.py` with super-admin and teacher passwords to refresh `unit-30-activity-gate.md`.

## Expected pass criteria (Unit 30 Activity)

- Distinct learning objective (not the title)
- **What the teacher does:** 3+ timed steps
- Numbers and a worked example from the unit in **What students do**
- Not the stub: `not complete enough to teach`
- Not a hollow `relay` with no angles
